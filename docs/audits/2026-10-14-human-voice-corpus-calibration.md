## 二、修正的动作（本次实际改了什么）

### 2.1 `FLAT_RUN_LEN` 3 → 4（有证据的阈值调整）

- 校准前：6 篇里 **5 篇**命中 `flat-rhythm`，且每篇的命中都是「恰好 3 句」的连串（唯一的例外
  是《比目魚》的 7 句连串）。
- 机器腔样本（`machine_probe` 的 `AI_FLAVORED`）在**该规则上原本就零命中**（它命中的是
  embodied-only / fancy-speech-tags / connective-stack / disyllabic-padding / abstract-wrapper）。
- 结论：「3 句近等长」是噪声门而非判别门——人类文本里本就常见。提到 4 后人类语料只剩
  1/6 篇命中（7 句连串），机器腔命中数不变（5 条）。
- 契约同步：`flat_rhythm_flags_uniform_sentence_run_but_not_varied_prose` 更新为「四句连串报、
  三句连串不报」；editor 审查清单的文字不变（LLM 侧仍按「连续三句以上」判断）。

### 2.2 指标与发现门解耦（顺手修掉的回归隐患）

`FLAT_RUN_LEN` 同时被用作**句长离散度指标**的段落过滤门（`sents.len() < FLAT_RUN_LEN → continue`）。
把发现门提到 4 会让指标跟着变（同一语料 SD 从 12–14 掉到 6–9）——指标是 v0.65.0 历史基线
（6.24 vs 14.97）的一部分，必须独立。新增 `SD_MIN_PARAGRAPH_SENTENCES = 3` 专供指标使用。

### 2.3 未动的规则与理由

| 规则 | 语料表现 | 决定 |
|---|---|---|
| `embodied-only` | 6 篇具身化计数全为 0（人类不靠身体反应承载情绪） | 不动（方向与 v0.65.0 一致） |
| `connective-stack` / `disyllabic-padding` / `abstract-wrapper` | 全 0 命中 | 不动 |
| `fancy-speech-tags` | 花式标签 0–2（从未达到门 3） | 不动 |
| `mood-particle-absent` | 1/6 篇误报（《木蘭奇女傳》20k 字全篇 0 语气词） | **不动**：现代人类语料语气词密度是机器 5 倍（v0.65.0 已验证），明清文言语域本就少语气词，据此放宽会削弱现代语域的判别力；该规则是 advisory，editor 也被明令不得据此判 blocking（`agency_editor_auditor_system.md`） |
| `uniform-paragraphs` | 段落 CV 0.20–0.29，**全部低于 0.30 门**，但零命中 | 不动，但记录一条重要事实：**CV 单独不具备判别力**（人类语料中位数 0.28 < 门 0.30），零误报靠的是合取条件「且无短段（≤40 字）」——该合取是承重的，后续不得拆开 |

## 三、边界与未关闭

- **语域边界**：明清白话 ≠ 现代网文。本报告的 SD/CV 分布偏保守（文言句式少变体、段落更整），
  不能当作现代语域的阈值依据；现代语域校准需要作者自己的旧稿（未开源）或另行采集。
- 探针不进 CI（`#[ignore]`）：语料缺失时打印跳过并返回（与 `machine_probe` 的真机库分支同款）。
- 命中 2/6 篇是**观测值**而非验收线：没有对「人类语料命中率上限」做断言——现有口径仍是
  「机器腔样本 ≥3 命中、人工撰写的对照样本 0 误报」（`machine_probe` 内硬断言，本次复跑未降）。
- 本次未改 editor 提示词与 `anti_ai` 规则；若后续接入现代语料，应同口径复核 `mood-particle-absent`
  与段落 CV 合取条件。
