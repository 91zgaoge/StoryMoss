# MCP 自动连接与幕后界面简化设计（v0.93.0）

> 日期：2026-11-08 ｜ 状态：已批准实施 ｜ 范围：幕后「设置 → 扩展 → MCP 连接」与「分析 → 续写训练」。

## 1. 目标

- 已保存的 enabled MCP 服务器在应用启动、打开 MCP 页、打开续写训练页时自动连接；
- 连接后全部工具自动注册并可用，不再要求用户逐个选择/填写工具名；
- UI 从「手动配置 + 手动执行」转为「连接状态 + 全部工具目录」；
- 权限仍由源系统契约控制，写/联网/隐私开关关闭时按 `MCP_*` 错误码拒绝。

## 2. MCP 连接页

```text
┌ MCP 连接                                       [重新扫描] ┐
│ 已连接 1/1 · 外部工具 11 · 映射 v1.0.0                    │
├ 服务器                                                  │
│ [栗子读书 HTTP · 已连接 · 11 工具 · 读取 · 联网 · v1.0.0] │
│ [重连] [停用] [删除]                                     │
│ [+ 添加服务器]（Modal：名称/传输方式/URL/token/命令）     │
├ 可用工具 11                                              │
│ 栗子读书 · 11 个工具                                     │
│ [list_books] [get_book] [list_chapters] ...              │
│ 点击工具 → 调试运行 Modal                                 │
└──────────────────────────────────────────────────────────┘
```

规则：
- 页面挂载自动 ensure 连接；失败只影响该服务器，卡片内联错误，可点重连；
- 无服务器时只显示空态与“添加服务器”，不显示完整手填表单；
- 配置表单移入 Modal，保存后自动连接；
- 工具目录按服务器分组展示全部工具；手动执行收进工具卡片的调试 Modal，不作为主界面；
- 状态 chips：连接数、外部工具数、映射版本；每台服务器显示权限 chips。

## 3. 续写训练页

```text
MCP 服务器   [自动选择首个 enabled 服务器 ▼]
章节正文工具 [自动选择（get_chapter_content） ▼]
[高级参数 ▾]  自动生成: {"book_url":"$book","index":"$index","fetch_online":true}
```

规则：
- 页面挂载/服务器列表更新时自动 ensure 连接并加载工具目录；
- 服务器默认首个 enabled 保存项；工具 Select 从当前服务器工具目录生成，默认优先
  `get_chapter_content`，其次名称/描述命中 chapter/content/正文；
- 参数模板自动按 JSON Schema 生成（书名/URL→`$book`，章节序号→`$index`，联网/正文开关→true），
  高级参数可覆盖；
- 后端兜底：`chapter_tool` 为空时自动挑选；`args_template` 为空时按 schema 生成；
- 后端执行时 `$book` 先经 MCP `get_book` 解析为 `book_url`，`$index` 数值化；失败回退书名并给出可读错误。

## 4. 安全与边界

- 自动连接仅针对用户显式保存且 enabled 的服务器，禁用/删除即断开；
- 全部工具注册不等于绕过权限：源系统写/联网/隐私关闭时查询仍报 `MCP_PERMISSION_DENIED`/`MCP_PERMISSION_CHANGED`；
- stdio 服务器也会尝试自动拉起其保存的 command；无命令/启动失败只影响该服务器状态；
- 训练自动解析 `book_url` 依赖源提供 `get_book`；没有该工具时保留书名作为占位并返回明确错误，不静默失败。
