# 幕后工作室精修与布局重建（设计契约）

> 日期：2026-11-06 ｜ 状态：已批准 ｜ 实施目标版本：v0.85.0
> 范围：幕后 `index.html` 应用。保留幕前、后端、IPC、业务数据与全部功能入口。
> 前置契约：`2026-11-04-backstage-ui-redesign-design.md`。本文针对真实安装包暴露的错位、裁切、遮挡与可读性问题继续精修，不改变既有信息架构与主题体系。

## 1. 问题与目标

用户实证：创作路径在窄栏中被压成逐字竖排；模型角色设置挤成一条且说明、温度控件失去正常列宽；普通 Panel 超过 1000px 后裁切，后续区块提前接上；场景预览/编辑的栏宽与 Grid 轨道不匹配；右下角幕前入口遮挡页面；导航组名仅 11px。既有视口探针只检查根节点横向溢出，不能证明可读、可滚动或无遮挡。

目标：在 800×600、1024×768、1400×900 及更宽桌面窗口中，均无逐字竖排、无失控列宽、无静态内容裁切、无浮层遮挡；所有主路径可滚动到底，视觉层级与操作位置稳定。

## 2. 设计定调：静谧的暗夜编辑台

- **产品气质**：专业、安静、可长时间使用的创作工具，而非营销页或炫酷仪表盘。
- **保留**：cinema 暗色基底、12 套传统色主题、film-grain、本地 LXGW/Cinzel 字体、双导航壳、5 组 23 项导航、既有 `--ai-*` API 与 Lucide 图标。
- **层次**：页面底色 → 工作区 → 卡片/表单；以细边框、间距与字面层级区分，不依赖叠加强渐变、光晕或大阴影。
- **强调色**：主题金只服务当前导航、主按钮、焦点和关键状态。语义状态色保持原义。
- **排版**：中文标题不强制 uppercase；正文约 14px，辅助文字至少 12px，导航组名至少 13px。数字使用 tabular-nums。技术名退居次要层级，不与用户任务争夺注意力。
- **密度**：控件紧凑、阅读舒展。沿用 4/8 间距标尺；控件圆角 8px、卡片 12px；不新增 pill 滥用。
- **动效**：只保留既有淡入、hover、press 与折叠反馈；尊重 reduced-motion，不引入自动播放演示。

## 3. 不变量

1. 不改幕前、IPC、Rust 业务逻辑与数据模型；不新增可见教学文案。
2. 导航 label、view key、设置 tab key、回调与保存语义不变；附录 B 的错误、校验、危险确认与状态文本逐字保留。
3. flex/grid 可收缩子项显式 `min-w-0 min-h-0`；并排布局按**实际容器宽度**而非只按视口决定。
4. 每页只有一个主滚动所有者；全高工作台的面板滚动必须建立在确定的 `h-full min-h-0` 链上。
5. 非折叠 Panel 高度由内容决定；折叠 Panel 不使用固定最大高度截断内容。
6. 任何固定宽度侧栏在空间不足时必须换行、堆叠或转入正常文档流，不得压缩正文到不可读。
7. 幕前入口属于导航普通布局，不再悬浮覆盖正文；连接状态全局只挂载一次。
8. 新增代码只使用 cinema/ai/status token，不写死新颜色；键盘焦点、ARIA 与 reduced-motion 不回归。

## 4. 页面契约

### 4.1 双导航壳

- Sidebar：品牌与幕前入口固定在结构内；中部导航独立滚动；组名 13px、增强对比；窄态提供可见的分组展开控件与 tooltip；当前故事与账号不挤压导航。
- StudioNavRail：与 Sidebar 共用 active 指示、hover/focus 与尺寸节奏；幕前入口位于底部普通布局。
- UserMenu：窄态只显示居中图标，菜单向上展开并留在视口内。

### 4.2 Dashboard / CreationPathGuide

- 顺序：页头 → 欢迎与主操作 → 统计 → 最近编辑 → 运行记录。
- 仅宽屏使用主区 + 320px 以上创作路径侧栏；中屏以下堆叠。
- CreationPathGuide 使用容器查询：窄容器单列、宽容器三列；三个入口、推荐标识与回调保持。
- 统计和最近编辑按可用空间回退，不允许以三列卡片撑出逐字竖排。

### 4.3 Settings

- 宽屏为设置导航 + 内容区，小屏保留横向页签；导入/导出位置稳定。
- 模型角色卡按容器分区分行：身份与说明、模型选择、温度/当前模型；字段保存和温度映射不变。
- Agent 八个映射卡保留三类模型与任务策略；控件栅格随容器从单列到多列，展开只增加正常文档流高度。
- 设置页可滚动到最后一个质检控件；没有静态 Panel 的 1000px 截断。

### 4.4 Scenes / SceneEditor

- Grid 轨道数与直接子级一致。大屏：故事线 / 阅读或编辑 / 执行；中屏两栏并为执行区指定明确区域；小屏单列。
- 阅读区优先保留可读宽度；故事线和执行栏有明确上下限与滚动归属。
- 编辑标题与操作可分组换行；阶段页签横向滚动；管线在空间不足时转到下方，在空间充足时为右栏。
- 管线折叠、AI 修稿/审稿/定稿、内容回写、保存/取消及版本对比行为不变。

### 4.5 其余工作台

- Foreshadowing、NarrativeAnalysis、BookDeconstruction、AgencyStudio 等已确认固定列点同步回退；不用根节点无横向溢出替代局部可读性验收。
